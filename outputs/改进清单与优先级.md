## 二、🔴 高优先级改进项（必做）

**目的**：验证最优解的鲁棒性，证明解不在"悬崖边"

**方法**：在最优解 (x_t=0, y_t=0, W=6, h=3, n_rings=25) 附近做单变量扫描：

```python

    'W':   np.linspace(5.0, 7.0, 11),      # 镜尺寸 ±1m

    'n_rings': list(range(22, 29)),        # 环数 ±3
}

# 每次只变一个变量，其余固定，输出 P̄ 与 P/A
# 生成 5 张折线图 + 1 张汇总表
```

### 改进 2：分项效率饼图

**目的**：拆解 5 项效率各自贡献，证明 η̄=0.5256 的物理合理性

**方法**：在年平均仿真中分别输出：

```python
eta_components = {
    'η_cos (余弦)':   0.65,   # 示例值，实际由代码计算
    'η_sb (阴影遮挡)': 0.92,
    'η_trunc (截断)':  0.85,
    'η_at (大气)':     0.97,
    'ρ (反射率)':      0.92,
}
# 总效率 = 各项乘积 ≈ 0.5256 × (1/ρ)  # 注意 ρ 已在总效率外
# 实际：η_total = ρ × η_cos × η_sb × η_trunc × η_at
```

**输出文件**：
- `outputs/figure/efficiency_breakdown_pie.png`（饼图）
- `outputs/figure/efficiency_breakdown_bar.png`（条形图对比）
- `outputs/data/efficiency_components.csv`

**验收标准**：
- η_cos 应在 0.55-0.75（北纬 39.4° 合理）
- η_sb 应 > 0.85（径向布局遮挡少）
- η_trunc 应 > 0.80（接收器 8×7m 足够大）
- η_at 应 > 0.95（高海拔 3km）

**风险提示**：若 η_trunc < 0.5，说明近场镜截断严重，需重新审视布局。

### 改进 3：加权方法对照表

**目的**：排除"权重选择影响结论"的质疑

**方法**：对同一镜场配置，用 4 种加权方式计算 P̄：

| 加权方式 | 公式 | 物理意义 |
|---------|------|---------|
| 等权平均 | w = 1/60 | 算术平均 |
| sin α_s 加权（当前默认） | w ∝ max(0, sin α_s) | 辐射贡献加权 |
| DNI 加权 | w ∝ DNI(t) | 能量加权 |
| 日照时长加权 | w ∝ (日照时长/12) | 季节代表性 |

**输出文件**：
- `outputs/data/weighting_comparison.csv`
- `outputs/figure/weighting_comparison.png`

**验收标准**：4 种方法的 P̄ 偏差 < 5%，则结论稳健。
**若偏差 > 10%**：必须在报告中明确说明加权选择依据。

## 七、风险与回退

| 风险 | 触发条件 | 应对 |
|------|---------|------|
| 敏感性分析显示解不稳定 | ±5% 扰动下 P/A 下降 > 5% | 重新优化，增加约束 |
| 分项效率异常 | η_trunc < 0.5 或 η_sb < 0.7 | 检查布局算法，排查截断 bug |
| 加权方法偏差大 | 4 种方法 P̄ 偏差 > 10% | 在报告中明确说明，补充讨论 |
| 问题三收敛曲线上穿 | DE 某代找到 > 525.9 的解 | 重跑问题三，扩大搜索范围 |
| 月度均值冬季过低 | 1 月均值 < 30 MW | 增加储能讨论章节 |
