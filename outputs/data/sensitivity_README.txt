敏感性分析采样模式说明 (Sensitivity Analysis Sampling Note)
=================================================================

本目录下 sensitivity_summary.csv 和 sensitivity_summary_v2.csv 中的
所有 P_avg_MW 使用快速采样模式（每月仅正午 12:00 一个时刻，共 12 时刻），
绝对值比完整 60 时刻采样高约 7-8%。

示例：
  baseline (x_t=0, y_t=0, W=6, h=3, n_rings=25):
    快速 12 正午采样：P = 65.19 MW
    完整 60 时刻采样：P = 60.58 MW（problem2_result.json 中的实际值）

用途说明：
  敏感性分析的目的不是精确量化绝对值，而是识别哪些变量值得花时间
  精细调优（高敏感度）以及哪些变量设个差不多就行（低敏感度）。
  因此使用快速模式仅关注"相对趋势"是合理的。

注意事项：
  - 不可将本表中 P_avg_MW 绝对值与 problem2_result.json 的 60.58 MW 直接比较
  - 如需精确绝对数值，请用完整 60 时刻采样重跑（预计总共约 20-25 分钟）
  - sampling_mode 列标注为 "fast_12noon" 表示使用了快速采样模式
